## Also fixed along the way

- **Saved projects lost fields:** SERVER `ProjectPayload.sketch` was a typed model, so curves (and
  now arcs' endpoints, hidden elements and positioning) were silently dropped on save. It is now
  stored as sent.
- **Tangent Arc tool:** the standalone Tangent Arc (Arc menu) always swept one way. It now uses
  the direction-aware `tangentArcFrom`, starts from the line's real endpoint, and adds a tangent
  constraint.
- **Arc centers:** fillet, slot and curved-slot centers were grid-snapped, which put the arc off
  its tangent points. They are now exact.
- **Solver:** internal circle tangency now solves (it was external-only).
- **Backend launch on macOS:** the committed `venv` is a Windows venv. `activate_venv.sh` picks
  a working environment or creates `.venv` with Python 3.12 (which build123d needs), and all the
  `.command` launchers use it.
- **CORS:** any localhost port is now allowed (vite preview, test server).
- **Docs rebuild:** `npm run publish:docs` rebuilds `docs/` and keeps `docs/reference/`. The
  README and `build_for_pages.command` use it (the launcher's wrong `cd` path is fixed too).
- **3D view:** its hint strip no longer blocks clicks on the navigation bar.
- **Toolbox:** it no longer scrolls sideways when a menu of tool variants opens.
- **Lint and types:** no type errors (2 before) and no lint errors (6 before). The unused
  constraint tools are now the toolbox's **CONSTRAINTS** section, which also handles arcs and the
  AbsoluteAxis.

## Pass 3 — known limits fixed, and a project-wide audit

- **Free-form curves are solver elements.** Ellipses, elliptical arcs, parabolas, hyperbolas,
  both spline kinds, and the rho and 5-point conics are all solver elements now
  (`sketch_curves.py` mirrors the canvas formulas). Tangency to any of them uses a touch-point
  unknown and is kept by every later solve. An ellipse's radii and rotation are solved, and it
  turns green when fully constrained.
- **Tri-Tangent Circle** now adds a real tangent constraint to each element. Its center is exact;
  it was grid-snapped, which broke the tangency.
- **Sketch on Face:**
  - The button is dynamic: disabled until a face is picked, then `/face_at` checks the real
    face. It only enables for a planar face, says why for a curved one, and toggles back to the
    XY stack when active.
  - H follows the face's longest straight edge.
  - The face's edges are projected into the sketch as construction lines.
  - The Sketch tab shows "On face".
  - The support is saved with the project.
- **3D view alignment (existing bug):** the view re-centres the part, but picks, the live sketch
  outline and reference geometry used model coordinates. All three are now converted, and the
  inertia centroid is reported in model coordinates.
- **Units:** constraint names and AI-import suggestions show the current unit.
- **Solve races:** only the newest solve response is applied, so a late one can't snap points
  back.
- **Solver speed:** it reuses least-squares' own Jacobian instead of recomputing it.
- **Arc edits** re-solve, so joined and tangent elements follow.
- **Backend URL:** `VITE_API_BASE` overrides it (for a hosted backend). The shared origin
  constant lives in `src/config.ts`.
- **Verification:** 25 backend tests, 16 unit tests, 14 browser tests (including the dynamic
  face button, a curved face rejected, and ellipse bi-tangency solved), 0 type errors, 0 lint
  errors, build and publish:docs passing.

## Pass 4 — T-junctions, tangency hints, trim, chamfer, file split

- **T-junctions / crossing lines extrude.** `profileLoops.traceLoops` is now a planar
  arrangement:
  - Lines are split wherever they touch or cross.
  - Coincident points are merged, dangling edges pruned, and duplicate lines dropped.
  - Each connected shape contributes its outer boundary, which is then split at pinch points.
- **Holes by containment.** The backend (`_loop_depths`) decides holes by containment depth, not
  by size. Side-by-side shapes both stay solid, and an island inside a hole is solid again.
- **Tangency hints while drawing** now also snap to ellipses, splines and conics (where the line
  runs along the curve's tangent). They add a solver tangent constraint.
- **Trim** cuts a circle to the arc that remains and splits an arc, between the crossings that
  bracket the click. Lines also trim against free-form curves.
- **Keyhole** is now one closed outline: the far arc of each circle joined by the two exact
  external tangents, with shared endpoints and tangent constraints. It extrudes as one keyhole.
- **2D Chamfer:**
  - Works on lines, arcs and circles, in **Two lengths** or **Length + angle** mode.
  - It had collapsed a rectangle into a trapezium, because the shared corner point was dragged
    to one cut. Each cut now gets its own point, and the old corner stays as a construction point
    (as in CATIA), so its dimensions still hold.
- **2D Fillet:** the same shared-corner bug is fixed.
- **3D Chamfer:** Equal distance / Length + angle / Two lengths (`chamferAngle`, `length2`), and
  a new **Curved edges** filter (circles, arcs, splines only). Fillet gets the same filter.
- **File split:** module-level code moved out of `SketchWorkspace.tsx` into `src/sketch/`:
  - `types.ts`
  - `constants.ts`
  - `geometry.ts`
  - `curves.ts`
  - `tools.ts`
  - `ToolButton.tsx`
  - `PlanePicker.tsx`

  The component itself is about 8,800 lines.

## Pass 5 — the last open items closed

- **Trim on free-form curves.** An ellipse (or elliptical arc) is cut to the exact elliptical arc
  that remains. A spline, parabola, hyperbola or conic becomes an interpolating spline through
  its own samples over the kept range, so it looks the same.
- **Chamfer on free-form curves.** The cut is walked along the curve to the chord distance, and
  the curve is trimmed the same way. A spline piece joins the chamfer line at a real point.
- **Windows launchers.** `start_backend.bat`, `start_frontend.bat` and
  `cad-server/activate_venv.bat`, which skips the empty committed `venv` and creates `.venv` with
  Python 3.12/3.11. Written with CRLF line endings; not run here (no Windows machine).
- **Backend access rules for hosting.** `FAELYX_CORS_ORIGINS` limits browser access to the listed
  sites; unset, only local dev ports are allowed. Covered by `tests/test_cors_config.py`.
- **Backend URL at runtime.** The GitHub Pages copy (or any build) can point at a backend via
  `?api=<url>` or the Style popover's **Backend URL** field, as well as `VITE_API_BASE`.
- **Hook warnings: 0 (was 8).** Window-level listeners call the latest helpers through a ref, so

- **Large sketches.** Curve samples are cached per render, point lookups use a map instead of

## Pass 6 — chamfer angle visibility, and the core split up

**Chamfer angle.** The options existed but were easy to miss:
- **Hidden in 2D:** the 2D bar opened in "Two lengths" mode, so the Angle field didn't show.
- **No lasting readout:** once applied, a chamfer showed no angle on the sketch.
- **Hard to find in 3D:** the 3D Chamfer defaulted to "Equal distance", its mode dropdown
  rendered tiny and grey, and Properties didn't open.

Now:
- **Default mode:** both 2D and 3D open in **Length + angle** at 45°, CATIA's own default.
- **2D preview:** reads "L 10.0 · 30.0°" live while hovering.
- **2D result:** adds a **Chamfer angle** constraint and a real angle dimension in the cut-off
  corner (it reads 30.0, not the 150.0 supplement).
- **3D:** choosing a tool opens **Properties**, and dropdowns there are full-size.

Browser tests check the default mode, the live readout, the constraint and the 30.0 dimension,
and that the 3D panel opens in Length + angle with Angle = 45.

**File split.** `useSketchCore.tsx` was 7,000 lines and is now 2,168 (125 KB): state, effects
and the solver link. Everything that only the views use moved into hooks in `sketch/handlers/`:
